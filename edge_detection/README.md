# Edge Detection

This project demonstrates edge detection on a grayscale image using three classical operators:

- Sobel operator
- Prewitt operator
- Laplacian operator

The implementation is written independently and uses direct 2D convolution rather than calling a ready-made edge detector.

## Input

A grayscale image is included as `input.png`.

## Output

Running `main.py` creates separate results for the Sobel X/Y gradients, Sobel edges, Prewitt X/Y gradients, Prewitt edges, and Laplacian edges inside `output/`.

## Run

Open the folder in VS Code and run `main.py`.
